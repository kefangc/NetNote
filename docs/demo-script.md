# 7 分钟演示脚本

1. 介绍痛点：课程资源分散、学生难以判断重点、缺少个性化练习闭环。
2. 打开系统，说明三栏结构：来源、来源问答、Studio。
3. 上传一份计算机网络资料，观察来源状态和自动概要。
4. 使用网络搜索补充 “TCP 拥塞控制”，将候选资料加入来源。
5. 在中间聊天区提问：“TCP 三次握手为什么需要第三次？”，展示带引用回答。
6. 生成闪卡，点击卡片翻转，标记会/不会，展示闪卡总结。
7. 生成测验，答题后展示选项内反馈，最后展示答题报告。
8. 生成思维导图，展开节点，点击节点向 AI 追问。
9. 展示学习画像：薄弱点、兴趣方向、正确率、下一步学习路径。
10. 总结竞赛要求覆盖：多智能体、个性化资源生成、路径规划、防幻觉、流式/进度体验。
