# 导论 马克思主义中国化时代化的历史进程与理论成果

**重要性：★★★★☆**

## 一、知识框架

### 1. 马克思主义中国化时代化

马克思主义中国化时代化，就是立足中国国情和时代特点，把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，解决中国革命、建设和改革中的实际问题，并形成具有中国特色、中国风格、中国气派的理论成果。

它不是照搬马克思主义经典作家的具体结论，也不是用中国传统文化替代马克思主义，而是坚持马克思主义立场、观点和方法，结合新的实践不断发展马克思主义。

### 2. 命题的提出

- 1938 年，毛泽东在党的六届六中全会上所作的《论新阶段》中，明确提出“马克思主义中国化”的命题。
- 实现马克思主义中国化时代化，是解决中国实际问题的客观需要，也是马克思主义理论本身发展的内在要求。

### 3. 理论成果之间的关系

- 毛泽东思想实现了马克思主义中国化时代化的第一次历史性飞跃。
- 邓小平理论、“三个代表”重要思想、科学发展观等构成中国特色社会主义理论体系的重要组成部分。
- 各理论成果一脉相承又与时俱进，共同坚持马克思主义基本立场，同时回答不同历史时期的重大实践问题。

## 二、易错辨析

1. “马克思主义中国化”的命题提出于 1938 年党的六届六中全会，不是遵义会议，也不是党的七大。
2. 党的七大的重要意义是把毛泽东思想确立为党的指导思想并写入党章。
3. 中国特色社会主义理论体系与毛泽东思想不是相互割裂的，两者一脉相承又与时俱进。
4. “中国化”不是把马克思主义变成地方性经验，而是运用和发展马克思主义。
5. 详细的习近平新时代中国特色社会主义思想内容不属于本次考试范围，但理论体系发展脉络要能辨认。

# 第一章 毛泽东思想及其历史地位

**重要性：★★★★★**

## 一、知识框架

### 1. 形成发展的历史条件

- 时代背景：战争与革命成为时代主题，俄国十月革命开辟世界无产阶级社会主义革命新时代。
- 实践基础：中国共产党领导人民进行革命和建设的成功实践。
- 文化基础：中华优秀传统文化。
- 理论基础：马克思列宁主义。

### 2. 形成发展的过程

| 阶段 | 主要内容 |
|---|---|
| 开始萌芽 | 中国共产党创建和大革命时期，提出新民主主义革命基本思想 |
| 初步形成 | 土地革命战争时期，开辟农村包围城市、武装夺取政权道路 |
| 趋于成熟 | 遵义会议以后至抗日战争时期，新民主主义革命理论形成完整体系 |
| 继续发展 | 解放战争时期和中华人民共和国成立以后，形成社会主义革命和建设的重要思想 |

### 3. 主要内容

毛泽东思想主要包括：

1. 新民主主义革命理论。
2. 社会主义革命和社会主义建设理论。
3. 革命军队建设和军事战略理论。
4. 政策和策略理论。
5. 思想政治工作和文化工作理论。
6. 党的建设理论。

### 4. 活的灵魂

- 实事求是：党的思想路线的核心，是毛泽东思想的精髓。
- 群众路线：一切为了群众，一切依靠群众，从群众中来，到群众中去。
- 独立自主：坚持中国的事情由中国人民自己作主张、自己处理。

### 5. 科学内涵与历史地位

毛泽东思想是马克思列宁主义在中国的创造性运用和发展，是被实践证明了的关于中国革命和建设的正确理论原则和经验总结，是中国共产党集体智慧的结晶。

历史地位：

- 马克思主义中国化时代化的第一次历史性飞跃。
- 中国革命和建设的科学指南。
- 中国共产党和中国人民宝贵的精神财富。

## 二、易错辨析

1. 毛泽东思想不等于毛泽东个人所有言论，错误观点不属于毛泽东思想科学体系。
2. 毛泽东思想是集体智慧的结晶，毛泽东作出主要贡献。
3. 遵义会议是毛泽东思想走向成熟的重要历史转折，但成熟的标志是新民主主义革命理论系统形成。
4. 实事求是是精髓，群众路线是党的根本工作路线，独立自主是革命和建设的基本立足点。
5. 评价毛泽东和毛泽东思想要坚持历史的、全面的观点。

# 第二章 新民主主义革命理论

**重要性：★★★★★**

## 一、知识框架

### 1. 形成依据

近代中国最基本的国情是半殖民地半封建社会。帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾，是近代中国社会的主要矛盾。近代中国革命的根本任务是推翻帝国主义、封建主义和官僚资本主义的统治。

### 2. 新民主主义革命总路线

无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。

| 要素 | 内容 |
|---|---|
| 对象 | 帝国主义、封建主义、官僚资本主义 |
| 动力 | 工人阶级、农民阶级、城市小资产阶级和民族资产阶级 |
| 领导力量 | 无产阶级及其政党中国共产党 |
| 主力军 | 农民 |
| 性质 | 资产阶级民主主义革命的新式特殊形态 |
| 前途 | 社会主义 |

### 3. 基本纲领

- 政治纲领：推翻帝国主义和封建主义压迫，建立无产阶级领导的、以工农联盟为基础的各革命阶级联合专政的新民主主义共和国。
- 经济纲领：没收封建地主阶级土地归农民所有；没收官僚资产阶级垄断资本归新民主主义国家所有；保护民族工商业。
- 文化纲领：无产阶级领导的人民大众的反帝反封建文化，即民族的、科学的、大众的文化。

### 4. 革命道路

中国革命必须走农村包围城市、武装夺取政权的道路。其根本原因是中国是一个政治经济发展不平衡的半殖民地半封建大国。土地革命是基本内容，武装斗争是主要形式，农村革命根据地是战略阵地。

### 5. 三大法宝

- 统一战线。
- 武装斗争。
- 党的建设。

统一战线和武装斗争是战胜敌人的两个基本武器；党的组织是掌握这两个武器以实行对敌冲锋陷阵的英勇战士。

# 第三章 社会主义改造理论

**重要性：★★★★★**

## 一、知识框架

### 1. 新民主主义社会的性质

从中华人民共和国成立到社会主义改造基本完成，是我国从新民主主义向社会主义过渡的时期。新民主主义社会不是独立的社会形态，而是带有过渡性质的社会。

新民主主义社会存在五种经济成分：

1. 社会主义性质的国营经济。
2. 半社会主义性质的合作社经济。
3. 农民和手工业者的个体经济。
4. 私人资本主义经济。
5. 国家资本主义经济。

其中，社会主义国营经济掌握主要经济命脉，居于领导地位。

### 2. 过渡时期总路线

1953 年，党正式提出过渡时期总路线。其主要内容是：从中华人民共和国成立，到社会主义改造基本完成，这是一个相当长的时期；要逐步实现国家的社会主义工业化，并逐步实现国家对农业、手工业和资本主义工商业的社会主义改造。

概括为“一化三改”：

- “一化”：社会主义工业化，是主体。
- “三改”：对农业、手工业和资本主义工商业的社会主义改造，是两翼。

社会主义建设和社会主义改造同时并举，发展生产力与变革生产关系同时进行。

### 3. 农业社会主义改造

农业改造遵循自愿互利、典型示范、国家帮助原则，采取循序渐进步骤：

| 形式 | 性质 |
|---|---|
| 互助组 | 社会主义萌芽性质 |
| 初级农业生产合作社 | 半社会主义性质 |
| 高级农业生产合作社 | 完全社会主义性质 |

### 4. 手工业社会主义改造

主要采取合作化道路，逐步由手工业供销小组、手工业供销合作社发展到手工业生产合作社。

### 5. 资本主义工商业社会主义改造

- 采用和平赎买的方法。
- 采取从低级到高级的国家资本主义形式。
- 初级形式包括委托加工、计划订货、统购包销、经销代销等。
- 高级形式包括个别企业公私合营和全行业公私合营。
- 全行业公私合营后，对资本家实行定息制度。
- 对资本主义工商业者实行团结、教育、改造的方针，把企业改造与人的改造结合起来。

### 6. 社会主义基本制度的确立

1956 年，社会主义改造基本完成，社会主义经济制度在中国基本建立，社会主义基本制度确立，我国进入社会主义初级阶段。

## 二、易错辨析

1. 过渡时期从 1949 年开始，到 1956 年社会主义改造基本完成，不是到 1957 年。
2. 新民主主义社会是过渡性社会，不是独立社会形态，也不是社会主义社会。
3. 过渡时期总路线的主体是社会主义工业化，两翼是三大改造。
4. 农业改造遵循自愿互利原则，不是行政命令强迫。
5. 对资本主义工商业采取和平赎买，是中国社会主义改造的创举。
6. 社会主义改造的实质是变革生产资料私有制，建立社会主义公有制。

# 第四章 社会主义建设道路初步探索的理论成果

**重要性：★★★★★**

## 一、知识框架

### 1. 初步探索的背景

社会主义改造基本完成后，如何在中国建设社会主义成为新的重大课题。照搬苏联模式不符合中国国情，党提出把马克思列宁主义基本原理同中国具体实际进行“第二次结合”，独立探索适合中国特点的社会主义建设道路。

### 2. 《论十大关系》

1956 年，毛泽东作《论十大关系》的报告，标志着党探索中国社会主义建设道路的良好开端。

报告确定的基本方针是：努力把党内党外、国内国外一切积极因素，直接的、间接的积极因素，全部调动起来，为社会主义建设服务。

十大关系重点讨论经济、政治、民族、党派和对外关系等问题，核心是以苏联经验为鉴，根据中国情况走自己的道路。

### 3. 社会主义社会矛盾理论

毛泽东指出：

- 社会主义社会仍然存在矛盾。
- 基本矛盾仍是生产关系和生产力、上层建筑和经济基础之间的矛盾。
- 社会主义社会基本矛盾具有“又相适应又相矛盾”的特点，可以通过社会主义制度本身不断得到解决。

社会主义社会存在两类不同性质的矛盾：

- 敌我矛盾：对抗性矛盾，用专政的方法解决。
- 人民内部矛盾：非对抗性矛盾，用民主的方法解决。

正确处理人民内部矛盾的总方针是用民主的方法解决，具体包括：

- 政治思想领域：团结—批评—团结。
- 物质利益、分配方面：统筹兼顾、适当安排。
- 人民群众和政府机关：民主集中制。
- 科学文化领域：百花齐放、百家争鸣。
- 共产党和民主党派：长期共存、互相监督。
- 民族关系：民族平等、团结互助。

### 4. 党的八大

1956 年党的八大正确分析国内主要矛盾。社会主义改造完成后，我国主要矛盾已经不再是工人阶级和资产阶级的矛盾，而是人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾。

党和全国人民的主要任务是集中力量发展社会生产力，把我国尽快从落后的农业国变为先进的工业国。

### 5. 中国工业化道路

毛泽东提出走一条有别于苏联的中国工业化道路：

- 以农业为基础，以工业为主导。
- 正确处理重工业、轻工业和农业的关系。
- 以农轻重为序发展国民经济。
- 兼顾国家、集体和个人利益，兼顾中央和地方。

### 6. 初步探索的意义和经验教训

意义：

- 巩固和发展社会主义制度。
- 为开创中国特色社会主义提供宝贵经验、理论准备和物质基础。
- 丰富和发展毛泽东思想。

经验教训：

- 必须把马克思主义同中国实际相结合。
- 必须正确认识社会主义社会主要矛盾和根本任务。
- 必须从实际出发进行社会主义建设。
- 必须发展社会主义民主、健全社会主义法制。
- 必须坚持民主集中制和集体领导。
- 必须坚持对外开放，学习外国有益经验，但不能照搬照抄。

## 二、易错辨析

1. 《论十大关系》标志探索良好开端，不是党的八大。
2. 社会主义社会没有矛盾是错误观点。
3. 敌我矛盾和人民内部矛盾性质不同，解决方法不能混用。
4. 党的八大关于主要矛盾的规范表述要与 1981 年、党的十九大等后来的主要矛盾表述区分。
5. 中国工业化道路不是放弃重工业，而是正确处理农、轻、重关系。
6. 初步探索有成就也有曲折，评价必须坚持历史和辩证观点。

# 第五章 中国特色社会主义理论体系的形成发展

**重要性：★★★★☆**

## 一、知识框架

### 1. 形成发展的社会历史条件

- 和平与发展成为时代主题，是中国特色社会主义理论体系形成发展的国际背景。
- 社会主义建设正反两方面历史经验和世界社会主义兴衰成败，是重要历史依据。
- 改革开放和社会主义现代化建设的伟大实践，是形成发展的实践基础。
- 中国特色社会主义进入新时代，推动理论体系继续丰富发展。详细的新时代思想内容不属于本次考试范围。

### 2. 形成发展过程

| 阶段 | 重要节点 |
|---|---|
| 开创 | 党的十一届三中全会开启改革开放；党的十二大提出“建设有中国特色的社会主义” |
| 初步形成 | 党的十三大系统阐述社会主义初级阶段理论和基本路线 |
| 系统概括 | 南方谈话推动思想解放；党的十四大系统概括中国特色社会主义理论主要内容并明确市场经济改革目标 |
| 正式命名 | 党的十五大正式提出“邓小平理论”，确立为指导思想并写入党章 |
| 跨世纪发展 | “三个代表”重要思想形成，党的十六大写入党章 |
| 新世纪新阶段发展 | 科学发展观形成，党的十八大确立为指导思想 |

### 3. 一脉相承、与时俱进

中国特色社会主义理论体系各组成部分：

- 坚持共同的理论基础和政治方向。
- 都以社会主义初级阶段为基本国情依据。

# 第六章 邓小平理论

**重要性：★★★★★**

## 一、知识框架

### 1. 首要的基本理论问题

邓小平理论围绕“什么是社会主义、怎样建设社会主义”这一首要的基本理论问题展开。过去社会主义建设出现曲折，一个重要原因是没有完全搞清楚这一问题。

### 2. 精髓

解放思想、实事求是，是邓小平理论的精髓。

- 解放思想：在马克思主义指导下打破习惯势力和主观偏见束缚，研究新情况、解决新问题。
- 实事求是：一切从实际出发，理论联系实际，在实践中检验和发展真理。
- 二者统一于建设中国特色社会主义的实践。

### 3. 社会主义本质

1992 年南方谈话中，邓小平概括社会主义本质：

> 解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。

这一概括把生产力和生产关系统一起来，把社会主义的根本任务和根本目标统一起来。

### 4. 社会主义初级阶段理论

- 我国已经是社会主义社会，必须坚持而不能离开社会主义。
- 我国社会主义还处在初级阶段，必须从这一实际出发，不能超越阶段。
- 社会主义初级阶段是特指我国生产力落后、商品经济不发达条件下建设社会主义必然经历的阶段。
- 从社会主义改造基本完成到社会主义现代化基本实现，至少需要上百年。

### 5. 党在社会主义初级阶段的基本路线

领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强、民主、文明的社会主义现代化国家而奋斗。

核心内容概括为“一个中心、两个基本点”：

- 一个中心：以经济建设为中心。
- 两个基本点：坚持四项基本原则，坚持改革开放。

四项基本原则是立国之本，改革开放是强国之路。

### 6. 改革开放理论

- 改革是社会主义社会发展的直接动力，是中国的第二次革命。
- 改革不是改变社会主义基本制度，而是社会主义制度的自我完善和发展。
- 对外开放是我国必须长期坚持的基本国策。
- 判断改革和各方面工作是非得失的标准是“三个有利于”：是否有利于发展社会主义社会生产力，是否有利于增强社会主义国家综合国力，是否有利于提高人民生活水平。

### 7. 社会主义市场经济理论

- 计划和市场都是经济手段，不是区分社会主义和资本主义的本质标志。
- 社会主义也可以搞市场经济。
- 社会主义市场经济把社会主义基本制度同市场经济结合起来。
- 党的十四大明确建立社会主义市场经济体制的改革目标。

### 8. 发展战略

“三步走”战略：

1. 第一步，到 20 世纪 80 年代末，国民生产总值翻一番，解决人民温饱问题。
2. 第二步，到 20 世纪末，国民生产总值再翻一番，人民生活达到小康水平。
3. 第三步，到 21 世纪中叶，人均国民生产总值达到中等发达国家水平，人民生活比较富裕，基本实现现代化。

邓小平反复强调：

- 发展才是硬道理。
- 科学技术是第一生产力。
- 尊重知识、尊重人才。
- 物质文明和精神文明“两手抓、两手都要硬”。

### 9. “一国两制”

“一国两制”的基本内容：

- 坚持一个中国是核心和前提。
- 国家主体坚持社会主义制度。
- 香港、澳门、台湾保持原有资本主义制度和生活方式长期不变。
- 特别行政区实行高度自治。

最初是为解决台湾问题提出，首先成功运用于香港、澳门问题。

## 二、易错辨析

1. 社会主义本质不等于社会主义基本制度，也不等于共同富裕一项内容。
2. 共同富裕不等于同步富裕、同时富裕或平均主义。
3. 基本路线的中心是经济建设，四项基本原则是立国之本，改革开放是强国之路。
4. 改革是社会主义制度的自我完善和发展，不是否定社会主义制度。
5. 市场经济不是资本主义特有，计划经济也不是社会主义的本质特征。
6. “一国两制”的核心和前提是一个中国，国家主体实行社会主义制度。

# 第七章 “三个代表”重要思想

**重要性：★★★★★**

## 一、知识框架

### 1. 回答的重大问题

“三个代表”重要思想在新的历史条件下进一步回答了什么是社会主义、怎样建设社会主义的问题，创造性回答了建设什么样的党、怎样建设党的问题。

### 2. 核心内容

中国共产党必须始终：

1. 代表中国先进生产力的发展要求。
2. 代表中国先进文化的前进方向。
3. 代表中国最广大人民的根本利益。

三者是统一整体：

- 先进生产力是发展先进文化、实现人民根本利益的基础条件。
- 人民群众是先进生产力和先进文化的创造主体，也是根本利益的主体。
- 不断发展先进生产力和先进文化，归根到底是为了实现最广大人民根本利益。

### 3. 关键、核心、本质

- 贯彻“三个代表”重要思想，关键在坚持与时俱进。
- 核心在坚持党的先进性。
- 本质在坚持执政为民。

### 4. 发展是党执政兴国的第一要务

- 发展是硬道理，解决中国所有问题的关键要靠自己的发展。
- 发展必须以经济建设为中心，同时推动政治、文化和社会全面进步。
- 走新型工业化道路，实施科教兴国战略、可持续发展战略和西部大开发战略。
- 正确处理改革、发展、稳定的关系。

### 5. 建立社会主义市场经济体制

- 坚持和完善社会主义基本经济制度。
- 公有制为主体、多种所有制经济共同发展。

- 发挥市场在资源配置中的基础性作用，加强和改善宏观调控。

### 6. 全面建设小康社会

党的十六大提出全面建设小康社会的奋斗目标，使经济更加发展、民主更加健全、科教更加进步、文化更加繁荣、社会更加和谐、人民生活更加殷实。

### 7. 社会主义政治文明和先进文化

- 发展社会主义民主政治，建设社会主义政治文明。

### 8. 党的建设

- 坚持立党为公、执政为民。
- 以改革精神推进党的建设新的伟大工程。

# 第八章 科学发展观

**重要性：★★★★★**

## 一、知识框架

### 1. 回答的重大问题

科学发展观深刻回答了新形势下实现什么样的发展、怎样发展等重大问题，是中国特色社会主义理论体系在新世纪新阶段的接续发展。

### 2. 科学内涵

| 内容 | 规范表述 |
|---|---|
| 第一要义 | 发展 |
| 核心立场 | 以人为本 |
| 基本要求 | 全面协调可持续 |
| 根本方法 | 统筹兼顾 |

### 3. 以人为本

- 全心全意为人民服务是党的根本宗旨。
- 发展为了人民、发展依靠人民、发展成果由人民共享。
- 以人为本的“人”是最广大人民群众，不是抽象个人或少数利益群体。
- 保障和改善民生，促进人的全面发展。

### 4. 全面协调可持续

- 全面：经济、政治、文化、社会等各方面共同发展。
- 协调：各方面、各环节发展相互适应。
- 可持续：促进人与自然和谐，实现经济发展和人口、资源、环境相协调。

### 5. 统筹兼顾

坚持统筹：

- 城乡发展。
- 区域发展。
- 经济社会发展。
- 人与自然和谐发展。
- 国内发展和对外开放。

同时统筹中央和地方、个人利益和集体利益、局部利益和整体利益、当前利益和长远利益。

### 6. 社会主义和谐社会

社会主义和谐社会的总要求：

1. 民主法治。
2. 公平正义。
3. 诚信友爱。
4. 充满活力。
5. 安定有序。
6. 人与自然和谐相处。

社会和谐是中国特色社会主义的本质属性。

### 7. 发展方式和重大战略

- 走新型工业化道路。
- 建设社会主义新农村。
- 建设创新型国家。
- 建设资源节约型、环境友好型社会。
- 推动区域协调发展。
- 加快转变经济发展方式。
- 实施科教兴国战略、人才强国战略和可持续发展战略。

### 8. 社会主义核心价值体系

基本内容：

1. 马克思主义指导思想。
2. 中国特色社会主义共同理想。
3. 以爱国主义为核心的民族精神和以改革创新为核心的时代精神。
4. 社会主义荣辱观。

### 9. 党的建设

- 加强党的执政能力建设。
- 保持和发展党的先进性。
- 坚持立党为公、执政为民。
- 坚持科学执政、民主执政、依法执政。
- 加强反腐倡廉建设和党的纯洁性建设。

## 二、易错辨析

1. 第一要义、核心、基本要求、根本方法不能错位。
2. 以人为本不是以个人利益为本，而是以最广大人民根本利益为本。
3. 科学发展观不是不要发展，而是强调又好又快、全面协调可持续发展。
4. 和谐社会不是没有矛盾，而是能够正确处理矛盾、保持活力和秩序的社会。
5. 统筹兼顾不是平均用力，而是把握全局、协调重点和各方利益。

# 最后背诵清单

## 一、必须完全准确的对应关系

1. 毛泽东思想活的灵魂：实事求是、群众路线、独立自主。
2. 新民主主义革命总路线：无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命。
3. 新民主主义革命三大法宝：统一战线、武装斗争、党的建设。
4. 过渡时期总路线：一化三改；一化是主体，三改是两翼。
5. 《论十大关系》基本方针：调动一切积极因素为社会主义建设服务。
6. 两类矛盾：敌我矛盾用专政方法，人民内部矛盾用民主方法。
7. 邓小平理论首要问题：什么是社会主义、怎样建设社会主义。
8. 社会主义本质：解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。
9. 基本路线核心：一个中心、两个基本点。
10. 四项基本原则是立国之本，改革开放是强国之路。
11. “三个有利于”：生产力、综合国力、人民生活水平。
12. “三个代表”：先进生产力、先进文化、最广大人民根本利益。
13. “三个代表”关键、核心、本质：与时俱进、党的先进性、执政为民。
14. 科学发展观：第一要义发展、核心以人为本、基本要求全面协调可持续、根本方法统筹兼顾。
15. 和谐社会总要求：民主法治、公平正义、诚信友爱、充满活力、安定有序、人与自然和谐相处。

1. 六届六中全会：提出马克思主义中国化命题。

## 三、考场策略

- 看到“根本、核心、首要、第一、标志、正式、系统”等词，先辨认限定词，再选答案。
- 多选题不以选项数量判断，逐项核对教材表述。
- 判断题中“完全、唯一、立即、自然消失、全部完成、任何时候”等绝对化措辞往往是陷阱。
- 材料题先判断所属理论和章节，再把材料中的关键词对应到教材概念。
- 不要把毛泽东思想、邓小平理论、“三个代表”重要思想和科学发展观的时代课题混淆。
